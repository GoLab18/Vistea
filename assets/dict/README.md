# Frequency word lists

Source: [hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords) (2018 English and Polish lists), licensed under the MIT License (see `LICENSE.txt`). Each list holds one entry per line in the format `word count`, ordered from most to least frequent, and drives the on-screen keyboard's word suggestions. The user's own additions live separately in `logs/user_dictionary.json` and are not shipped here.
